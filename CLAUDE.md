# MaiaFlow

Task and habit tracker: ASP.NET Core (.NET 10) + PostgreSQL API in `backend/MaiaFlow`, Next.js
web app in `frontend/`.

## Start here

Work is organized in phases. At the start of every session:

1. Read [`docs/ROADMAP.md`](docs/ROADMAP.md): phases, status, working agreement, and decisions.
2. Read the handoff of the last finished phase in [`docs/handoffs/`](docs/handoffs/).
3. Continue with the first phase whose status is not `Done`.

## Conventions

- Code, comments, commit messages, and docs in English; user-facing UI text in Brazilian
  Portuguese.
- Conventional Commits with scope (`feat(api): ...`, `fix(web): ...`). Commit each piece of
  work as soon as it is finished and checked.
- One pull request per phase. At the end of a phase, write `docs/handoffs/phase-N.md` from the
  template and update the status table in the roadmap.
- Decisions listed in the roadmap are settled; ask the owner before changing them.
